# Development data

The 20 questions in `dev.jsonl` refer to `examples/technical-catalog.pdf`. Generate the PDF with `python scripts/make_examples.py`; the application also generates it on first startup. All sample content is fictional and original to this project, released under CC0-1.0.

See [evaluation methodology](../docs/EVALUATION.md) before interpreting results. The dataset is for development, not held-out assessment. No accuracy claim should be inferred from the number of automated software tests.
